- [触发条件]中间骨骼(_M)执行拷贝翻转 -> [根因]直接暴力翻折全量 World Matrix (S_x * WS_max * S_x) 导致包含着预设角度偏移（比如基础带 -90度 Y 轴偏转）的 BasePose 也被整体颠倒至异侧，产生严重的轴向混乱 -> [正确方案]改用计算 Target 到 Base 的 Local Offset Delta 并对 Delta 执行 S_x * Delta_R * S_x 来剥离世界翻转与本地基础角度，最后组合还原。 -> [避坑规则]所有的中间部位骨架镜像严禁翻转原生 Transform 系，必须走位移/偏差特征镜面反射！
- [触发条件]未选中模型操作时多边形拷贝翻转失效 -> [根因]原先的 run_joint_or_polygon 代码绑定了对当前 Maya Object Select 列表的状态检测，没选中模型就直接跳过。 -> [正确方案]修改底层的 mirror_polygon_targets 去直接扫描 aliasAttr 定位匹配的 blendShape 节点自动建立。 -> [避坑规则]封装通用的数据读写管道时禁止强耦合 UI 层面的鼠标选中判断。
